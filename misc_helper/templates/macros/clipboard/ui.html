{# Clipboard UI components. ========================================================================================= Markup adapted from Penguin UI (MIT, Copyright (c) Salar Houshvand) -- https://github.com/SalarHoushvand/penguinui-components. See NOTICE at the repo root. Two systematic changes were made to every component taken from there, and both matter: 1. EVERY `dark:` VARIANT IS STRIPPED. Penguin UI writes each colour twice because Tailwind's `dark:` follows prefers-color-scheme. Frappe stamps [data-theme="dark"] on the root instead, and the espresso variables behind these token names already swap underneath us. Keeping `dark:` would make the page follow the OS and ignore the user's chosen Frappe theme. 2. HARDCODED PALETTE CLASSES ARE REPLACED BY SEMANTIC ONES. Penguin UI's alert, for instance, ships `border-sky-500 text-sky-500`; that is a literal colour with no dark-mode counterpart here, so it becomes `border-info text-on-info`. Preflight is deliberately not imported (it would strip Frappe's chrome), so Bootstrap's own element styles survive and every macro below carries its own resets -- `m-0` on headings, `p` and `pre`, `list-none pl-0` on lists.
